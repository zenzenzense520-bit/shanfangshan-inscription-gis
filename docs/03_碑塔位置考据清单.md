# 上方山碑塔位置考据清单

> 配套文档：《01_碑文逐条摘录.md》《02_思想提炼.md》
> 用途：QGIS 刺点与影像判读的作业底表
> 标记说明：**山内/山外** = 是否在景区核心区；**作业方式** = 影像刺点 / 实地实测 / 文献考证

---

## 〇、工作方法

1. **影像刺点（主）**：以高分影像（0.8m 级）为底图，按碑文方位词（西峰、西崖、西南隅、摘星砣等）+ 现地高程/建筑遗迹判读落点。
2. **实地实测（辅）**：对景区可达、且碑塔仍有遗存的点位，用 HGO/RTK 测 5~8 个控制点，用于校核刺点系统偏差。
3. **文献考证**：山外点位（孤山口村、六聘山、太湖东南）以及位置词存疑的碑塔，须先查《上方山志》《房山县志》、文物普查记录确定落点范围，再决定是否刺点。

## 四、待考证问题清单

1. **"神隅"**（忏悔塔）：辽塔方位中"神隅"确指何方向？

### 5.3 山脉-殿阁格局（卷之四 · 上方山记）

自如众《上方山记》以风水堪舆方式记述山形与殿阁关系，可作刺点辅助参考：

> "自孤山口抵兜率门，计十五里，由发污岭，步云梯而达内院也。山位子午，一干七枝……"

| 山峰/崖 | 殿阁/庵 | 比喻方位 |
|---|---|---|
| 象王峰 | 普贤殿 | 挂其鼻祖（头部） |
| 峭壁峰 | 狮子崖 | 负其来脊（脊背） |
| 锦绣峰 | 兜率寺 | 抱其中心（中心） |
| 毗卢顶 | 毗卢庵 | 居其颔下（下颌） |
| 回龙峰 | 文殊殿 | 坐其胸堂（胸部） |
| 啸月峰 | 观音阁 | 起其肚腹（腹部） |
| 普陀崖 | 观音殿 | 隐其肩井（肩部） |

- **解读**：兜率寺位于山体中心（锦绣峰），文殊殿在北偏东（回龙峰/胸堂），观音殿在东侧偏南（普陀崖/肩井），普贤殿在东北（象王峰/鼻祖）。这与碑文"左普贤、右文殊、环卫观音地藏"的空间格局基本一致。

### 5.4 善信碑记目录（卷之二 · 善信）

《上方山志》明确记载了与碑文对应的重修碑记：

1. **宏治年重修天梯**：御用监太监王公瑞，兜率有碑记 → 对应碑文 01《重修上方兜率寺天梯记铭》
2. **嘉靖重修兜率**：司礼监太监李中轩 → 对应碑文 02《重修兜率禅寺记》
3. **万历年重修观音阁**：惜薪总理司御马监太监李志义 → 对应碑文 03 中提及的李志义
4. **大清康熙年重修文殊殿**：范佑民、邵应文、李斯琛等率众捐资有碑 → 对应碑文 03《重修上方山文殊殿常明香灯记》
