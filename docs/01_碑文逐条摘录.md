# 上方山碑刻原文逐条摘录

> 来源：《重修上方兜率寺天梯记铭.docx》（共收录碑文/塔记 17 篇）
> 编制：上方山碑刻 GIS 实习报告项目

---

## 一、总述

本篇文书实为上方山（旧称"上房山"）一组碑刻文字的汇编，内容以**塔记、塔铭**为主，兼有**寺庙重修记、灯香记、禅师行实记**，时间跨度自**唐**（神龙年间）至**清乾隆**，核心为**明代宫廷太监捐资修缮**与**禅宗僧人塔葬**两条主线，是研究上方山佛教兴衰、明代宦官佛教信仰及僧团行实的珍贵石刻文献。

## 二、逐条摘录

### 01 重修上方兜率寺天梯记铭

| 属性 | 内容 |
|---|---|
| 类型 | 修梯记铭 |
| 位置 | 上方山天梯（兜率寺前通道） |
| 立碑年代 | 明·弘治七年（1494）岁在甲寅夏六月吉日 |
| 撰文人 | 彭礼（赐进士第，太仆寺卿） |

**原文摘录**：

> 御用监太监王公瑞奉上命往小西天给散布施，事竟，复命路经天梯，见石硁崎岖，坡崖陡峻，上下往来者甚艰。若非攀引，则不可进，否则有颠仆之虞。
>
> 僧曰：此梯高拔天成也。寺必因梯而立石，其来远甚。肇建元末，屡遭兵燹……迨我圣朝……永乐间，住山僧然义，偕内官监太监向公、福善倪公忠，重修梯道，以便往来。
>
> 公闻之，此志遂决，捐囊金，鸠材石……未几，化崎岖而为坦夷，易蓁莽而为福地。

**要点**：明弘治六年（1493）御用监太监王瑞奉敕往小西天布施，回程途经天梯见石硁崎岖，遂捐资重修。碑文追溯天梯肇建于元末、明永乐间已重修，反映上方山天梯为进寺咽喉要道。

### 02 重修兜率禅寺记

| 属性 | 内容 |
|---|---|
| 类型 | 寺院重修记 |
| 位置 | 上房山巅·兜率寺 |
| 立碑年代 | 明·嘉靖戊申（1548）岁孟夏 |
| 撰文人 | 杨震（赐进士第） |

**原文摘录**：

> 都城之西南隅有房山者，苍颜秀壁，盖名山也。其中有上房山。兜率寺者，名借上方六欲第四天之宫名也，盖因山之巅崖拔出，而寺居其上也。
>
> 惟司礼监太监中轩李公闻而叹曰：兴衰举废，古人至意……乃捐俸金，搆材鸠工以兴之，未逾年而告成。殿前增天王者四，又增弥勒伽蓝、祖师别殿，置大藏尊经并中殿。

**要点**：释"兜率"寺名——借"上方六欲第四天"（兜率天）之宫名，因寺居山巅。嘉靖间司礼监太监李公捐俸重修，增天王殿、弥勒伽蓝、祖师别殿、大藏经等，规模大备。**此记为宦官捐资修寺的代表作。**

### 03 重修上方山文殊殿常明香灯记

| 属性 | 内容 |
|---|---|
| 类型 | 殿宇香灯记 |
| 位置 | 上方山·西茶罗顶（文殊殿） |
| 立碑年代 | 清·康熙十二年（1673）壬子中秋 |
| 撰文人 | 苏宣化（翰林院编修加二级） |

**原文摘录**：

> 是则有毗卢顶、兜率寺，宗其主也；东象王山、普贤殿，辅其左也；西茶罗顶，文殊殿，政其右也。紫云岩、摘星陀、观音殿、地藏殿环其卫也。次有涅龙潭、斗笠泉，仰华严祖师之灵迹也。
>
> 李志义者，乃明神宗时惜薪司总理御马监太监也，捐俸修阁，津梁犹在，唯文殊殿尚待其人……是以感发诚心，遂有香燎斋僧之举。

**要点**：此文详述上方山**建筑空间格局**——以兜率寺为主，左普贤殿、右文殊殿、观音殿地藏殿环卫，并载云水洞、摘星陀等灵迹，是**刺点定位的极佳地理文献**。发心弟子范佑民、邵应文、李斯琛率众捐资重修。

### 04 百咏南禅师塔记

| 属性 | 内容 |
|---|---|
| 类型 | 塔记 |
| 位置 | 上方山西峰·西崖练若 |
| 立碑年代 | 北齐后主隆化元年（569）重阳日纪（存疑，疑为辽金时追记） |
| 撰文人 | 范阳张鹍（佛门弟子） |

**原文摘录**：

> 邺水赵氏，师之籍也。总角业儒，中年不第……来山结茅，心知止也。西峰幽静，择其地也。西崖练若，颜其额也。昼夜礼诵，寒暑不辍，勤也。
>
> 行年七十九，悟物非我有。玄辩并枢机，悉系水上沤。赤膊臭肉团，奔波弗记秋。一朝心放下，从此梦亦休。

**要点**：俗姓赵，邺水人，中年不第后出家，来上方山结茅西峰，号"百咏"因"咏歌纯熟，如瓶泻水"。碑文言"天宝年"祈雨，落款"北齐后主隆化元年"与正文唐天宝年号矛盾，**时代存疑，需在报告中注明**。

### 05 明禅师塔铭

| 属性 | 内容 |
|---|---|
| 类型 | 塔铭 |
| 位置 | 上方山 |
| 立碑年代 | 金·大定二年（1162）子月 |
| 撰文人 | 善阳沙门行（莫山主沙门圆晖托） |

**原文摘录**：

> 道人善明尝此乐，七十七年惟自若。赵姓，宝坻本村落……未后上方得栖托，便把拄杖高挂却。大定丁丑岁将涸……
>
> 积薪自焚贵省要，如烧玉石无秽恶。信戒定慧非凡壳。……收拾余骨藏石椁，表窣堵波觉后觉。

**要点**：俗姓赵，宝坻人，金大定年间于上方山坐化，弟子积薪茶毗、收骨藏石椁、立窣堵波。塔铭为七言偈语体，反映金代上方山禅僧"草衣木食、乐居崖壑"的苦行风尚。

### 06 钦凿拙崖篮和尚塔记

| 属性 | 内容 |
|---|---|
| 类型 | 塔记 |
| 位置 | 上方山·西南隅崖下（极乐庵） |
| 立碑年代 | 唐·肃宗宝应癸卯（763）前后（后立碑） |
| 撰文人 | 佚名 |

**原文摘录**：

> 师不知何许人氏，于唐中宗神龙庚午孟夏来山……师于西南隅结茅崖下，曰诵楞严心印之旨。……开元癸丑，冯秉篡筑极乐庵于崖，为师休栖。师暇把条编筐，置路，任人取去，以故人皆谓之篮和尚。
>
> 偈云：住世入十九，磨性编筐篓。赠君疋素布，送我西方走。

**要点**：唐神龙年间（710）来山，结茅西南隅崖下，以编筐置路任人取用得名"篮和尚"，谶言有验。开元癸丑（713）建极乐庵。**塔记落款年代与正文纪年需复核**。

### 07 忏悔上人塔记

| 属性 | 内容 |
|---|---|
| 类型 | 塔记 |
| 位置 | 上方山本院·神隅 |
| 立碑年代 | 辽·大安六年（1090）姑洗月望日 |
| 撰文人 | 王虚中（朝议大夫、乾文阁直学士） |

**原文摘录**：

> 上人讳守常，曹姓，易县新安人也。幼习儒业……于六聘山拜铁头陀为师。十九受具……住持本山，几四十年。曰诵大悲以为恒……以咸雍六年迁化上方，春秋六十一，夏腊四十二而去后顶暖，其容如生。

**要点**：俗姓曹，易县新安人，辽代僧人，六聘山铁头陀弟子，住持上方山近四十年，每日诵《大悲咒》。咸雍六年（1070）迁化，身后"顶暖、容如生"，弟子建塔于本院。**辽代上方山佛教的实证。**

### 08 遐龄益寿禅师塔记

| 属性 | 内容 |
|---|---|
| 类型 | 塔记（皇帝敕建） |
| 位置 | 上方山·西峰之侧 |
| 立碑年代 | 金·海陵王正隆元年丙辰（1156）九月初三日 |
| 撰文人 | 冯国相（朝议大夫、文华殿大学士） |

**原文摘录**：

> 师字天空，讳禅悦，昌平柳村郑氏之子也……居卧云庵二十余载，蔬食苦行，常修百舟三昧。上闻其德，下诏师辞，连诏者三，遂应诏入都……就宫供养，遂开阐护国仁王般若尊经……赐号遐龄益寿禅师。
>
> 丙辰季秋甲子示寂……藏于西峰之侧。春秋九十有七，法腊六十二。上赐白镪三百两，为之建塔，树碣以纪之云。

**要点**：俗姓郑，昌平人，居卧云庵二十余载苦行。金帝三次下诏方应召入宫，赐号"遐龄益寿禅师"并赐御赞，示寂后皇帝遣祭、赐银三百两建塔于西峰之侧。**金代帝王崇佛与上方山高僧受封的典型文献。**

### 11 文济开山第一代孤山银师塔记

| 属性 | 内容 |
|---|---|
| 类型 | 塔记（开山祖师） |
| 位置 | 孤山口村·尊济禅寺西北隅 |
| 立碑年代 | 明·崇祯甲申（1644）春旦 |
| 撰文人 | 佚名 |

**原文摘录**：

> 师俗李姓……少侍比庭银作局……出内徧游南海诸名胜，至少林，遇道公无言师披剃，法名银圆。居数时，来隐上方，构朝阳庵息静……于孤山口村创建寺宇二座，曰尊济禅寺，以利往来。

| 撰文人 | 傅雯题 |

### 13 道潜真禅师塔记

| 属性 | 内容 |
|---|---|
| 类型 | 塔记 |
| 位置 | 上方山（文殊化愚师座下） |
| 立碑年代 | 清·康熙五十二年（1713）重阳日 |
| 撰文人 | 金台彭述古 |

**原文摘录**：

> 县西南隅孤山口村，师之籍也，郭世刘氏子。师龆年不乐童戏……遂送之于上方文殊化愚师座下，薙发为徒……
>
> 一日夜坐，忽见白光盈室，心神泰然。自后阅诸秘典，无不了了……康熙癸巳岁，师无恙而沐手着衣，跏趺而逝。师寿六十有九，佛腊四十九。

**要点**：俗姓刘，孤山口村人，幼年于上方山文殊殿化愚师座下出家，康熙五十二年（1713）跏趺而逝。弟子建塔作记。**孤山口村为上方山南麓村落，亦为进山门户之一。**

### 14 穆然普德禅师塔记

| 属性 | 内容 |
|---|---|
| 类型 | 塔记 |
| 位置 | 上方山·西崖石室 |
| 立碑年代 | 清·乾隆甲申（1764）夏 |
| 撰文人 | 清凉道人自如 |

**原文摘录**：

> 师籍蠡县小陈村翟姓，少侍内庭李公……康熙四十一年，师年三十六岁，于法通寺拜古林师披剃，名普德，字穆然……梁、李、魏三大监，愿捐俸金，鸠材工，将旧寺扩充一新，更名净因寺。
>
> 至上方，得药师殿，而志遂定，乃掷笊挂钵，整其旧田五顷……于乾隆七年壬戌春示微疾而终。世寿七十有七……葬于西崖之石室。

**要点**：俗姓翟，蠡县人，出身内廷服役，三十六岁出家，得梁、李、魏三大监捐俸扩建净因寺，后至上方山整药师殿、置田结缘。示寂后葬于**西崖石室**。反映清代太监与僧团的持续供养关系。

### 15 水月禅师行实记

| 属性 | 内容 |
|---|---|
| 类型 | 行实记（建塔以表其德） |
| 位置 | 上方山·山北翠微峰 |
| 立碑年代 | 清·乾隆丁卯（1747）春月吉日 |
| 撰文人 | 真州佛弟子方嶟拜撰 |

**原文摘录**：

> 师讳成渊，字水月，胡姓，母董氏，江右赣州龙南县人氏……得法于广润寺镜堂长老沉渊……住持方丈十三年。
>
> 乾隆元年，退院来京……而之上方结茅峰下……十一年秋八月望日，师忽不见，莫知何往。开户视之，惟一瓢一笠，二履一袜而巳。
>
> 越明年丁卯春，有樵青之沈姓，于山北翠微峰，见师端坐，是时巳六月越矣……大众积柴，即于峰顶举火……信女赵罗氏、李刘氏，及面会众善，捐资建塔，以表其德。

**要点**：俗姓胡，赣州人，得法于天台广润寺，曾住持方丈十三年。乾隆十一年（1746）于上方山结茅，忽不知所往，次年被人发现端坐于**山北翠微峰**，血肉不坏，众举火茶毗后葬骨建塔。为清代僧人"留形住世"传说的石刻记录。

### 16 道目禅师自序

| 属性 | 内容 |
|---|---|
| 类型 | 自序 |
| 位置 | 上方山·观音殿（主席） |
| 立碑年代 | 康熙年间（丙寅秋应祖庭请） |
| 撰文人 | 道目禅师自撰 |

**原文摘录**：

> 余闽南人也。时值闽海烽烟摇漾，旧林难问……来此山中，似有夙因，不觉心醉。
>
> 适王内臣以观音殿原系公建，请余主席，相送入山。余捐衣钵，重建殿宇，造款龙桥，山门重葺，开铺大道，修理普贤……自浙及燕，重来置产饭僧。
>
> 集此数言，以记始末，俾后住者知前苦心。

**要点**：闽南人，因闽海战乱出家入山，受内臣王姓所请住持观音殿，捐衣钵重建殿宇、修款龙桥、开铺大道。自述"自浙及燕，重来置产饭僧"，为**上方山观音殿住持的一手史料**。

| 撰文人 | 佚名 |

**原文摘录**：

> 筠客师者，嘉兴仲氏之子也。幼业儒，比长厌世累……依道目老人圆具……康熙老人重师性纯，堪为法器，是以印证，接续洞脉三十一世，令为上方观音住持。
>
> 居山三十五载，于辛丑七月十日，别众而终……塔其骨于山外西南太湖东南紫盖峰下碧云岭。

**要点**：俗姓仲，嘉兴人，道目老人（见篇16）之弟子，接续"洞脉三十一世"（曹洞宗法脉），任上方观音住持，居山三十五载。塔葬于**山外西南太湖东南紫盖峰下碧云岭**，为上方山外围点位。
